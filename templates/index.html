RID+PID Processor - Quick Guide
  • What This Tool Does: Analyzes survey respondent behavior by combining RID lookup data with historical PID metrics to identify potentially problematic participants across 6 different quality checks.
  • Easy File Upload:
    • Drag & Drop: Simply drag your CSV (RID) and Excel (PID) files into the upload zones, or click to browse
    • File Validation: Automatic file type checking with helpful error messages
    • Smart PIDs: When you upload a RID file, unique PIDs are automatically extracted and displayed in copy-ready format for SSRS input
    • File Previews: See file statistics (size, record counts, survey IDs) before processing
  • Survey LOI Input (Length of Interview):
    • Average LOI Mode: Enter one LOI value that applies to all surveys (default mode)
    • Survey-Specific Mode: Enter individual LOI values for each survey ID with direct Marketplace links
    • Smart Validation: LOI values must be between 3-100 minutes with real-time validation
  • Quality Checks Applied (in priority order):
    1. Low Conversion Rate: Identifies PIDs with poor survey completion rates (requires survey history)
    2. New User/Bot Suspect: Flags participants who entered and exited on the same day
    3. High Security Terms: Detects excessive security violation rates (requires survey history)
    4. Speeder: Identifies participants completing surveys too quickly
    5. High LOI/Distracted: Flags participants taking excessive time to complete
    6. High Reversal Rate: Detects participants with too many recommendation reversals (requires survey history)

    Smart Logic: Later checks override earlier ones. Clean participants show as: No Flags

  • Advanced Customization:
    • Session Checks: Adjust Speeder (÷3) and High LOI (×3) multipliers for current session analysis
    • Historical Checks: Set thresholds for conversion (10%), security terms (30%), and reversal rates (15%)
    • Experience Threshold: Minimum surveys (default: 5) required before applying historical checks
    • Auto-Save: All your settings are automatically saved in your browser
  • Comprehensive Excel Report (6 sheets):
    • Combined Data: Complete merged dataset with dynamic Excel formulas for real-time calculations
    • Summary Counts: Statistical overview with count tables and data bars for quick insights
    • Priority Analysis: Supplier breakdown showing the primary quality issue for each participant
    • Multi-Flag Analysis: Complete flag matrix showing all quality issues per supplier
    • Time Series - Flags: Quality trends over time by observation type
    • Time Series - Suppliers: Participation patterns over time by supplier
    • Deny List Draft: Filtered results ready for deny-list creation with proper formatting
  • User Experience Features:
    • Real-Time Validation: Process button shows exactly what's missing with helpful tooltips
    • Dark Mode: Toggle between light and dark themes (preference remembered)
    • Smart Error Handling: Detailed error messages with downloadable error reports when issues occur
    • Excel Intelligence: Formulas instead of static calculations for transparency and flexibility
    • Mobile Friendly: Responsive design that works on different screen sizes
