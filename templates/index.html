RID+PID Processor i
How This Tool Works
  • Processing Modes:
    • RID+PID Mode (Default):
      • Requires both RID Lookup CSV and PID Metrics Excel files
      • After RID file upload, Survey LOI section becomes available with mode toggle
      • All 6 observation checks are applied including session-based checks
    • PID-only Mode:
      • Requires only PID Metrics Excel file
      • RID file upload and Survey LOI inputs are automatically hidden
      • Only historical PID-based checks are applied (skips session LOI checks)
  • LOI Input Modes (RID+PID only):
    • Survey-specific LOI: Individual LOI values for each survey ID with direct Marketplace links
    • Average LOI: Single LOI value applied to all surveys with aggregated Marketplace link to top survey
  • Observation Checks & Priority Order:
    1. Low Conversion Rate: system_conversion_rate < threshold% & total_surveys_entered > threshold
    2. New User, First survey, Bot suspect: first_entry_date = last_entry_date (date-only comparison)
    3. High Security Terms Rate: security_terms_rate > threshold% & total_surveys_entered > threshold
    4. Low LOI, Speeder: session_loi < Survey_LOI/divider (RID+PID mode only)
    5. High LOI, Distracted: session_loi > Survey_LOI×multiplier (RID+PID mode only)
    6. High Reversal Rate: net_recs_rate > threshold% & total_surveys_entered > threshold

    Priority Logic: Later checks override earlier ones. If no checks match: No Flags

    Survey Count Condition: Three checks (Low Conversion, High Security, High Reversal) only apply when total_surveys_entered exceeds the threshold (default: 5)

  • Excel Output Report (6 sheets):
    • Combined Data: Merged dataset with all calculated columns and Excel formulas for dynamic calculations
    • Counts: Summary count tables with TRANSPOSE formulas referencing pivot data:
      • PrioFlag Counts (from priority-based observations)
      • MultiFlag Counts (from multi-flag analysis)
      • Individual counts for surveyid, response status, country, project manager, buyer BU
    • Flags Pivot (Priority): Supplier × single priority observation with conditional formatting
    • Flags Pivot (Multi): Supplier × all applicable flags showing complete flag analysis
    • Pivot EntryDate × Flags: Time-series analysis of observation types by date
    • Pivot EntryDate × Supplier: Time-series analysis of entries by supplier and date
    • DenyList_Draft: Filtered flagged records formatted for deny-list creation
  • Advanced Options:
    • RID checks (current session): Configure Speeder and High LOI multipliers/dividers
    • PID checks (historical data): Set thresholds for conversion rate, security terms, and reversal rate
    • Survey count threshold: Minimum surveys required for historical checks (4-20, default: 5)
    • All settings are automatically saved in your browser for convenience
  • Validation & Features:
    • File validation: CSV for RID, XLSX for PID Metrics - upload original files without modifications
    • LOI validation: Must be between 3-100, required in RID+PID mode
    • Real-time validation: Button tooltips show missing requirements, process button enables when ready
    • Dark mode support: Toggle between light and dark themes (preference saved)
    • Excel formulas: Most calculations use Excel formulas for transparency and performance

For queries/concerns, reach out to T&S team.
